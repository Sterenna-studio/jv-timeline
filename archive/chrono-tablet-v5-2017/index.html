Interface de saut temporel ludique — timeline des sorties de jeux majeurs par mois. BZH CHRONICLES UI.

MODULE G.A.M.E. CHRONO-ARCHIVE

Principe : ta date réelle est projetée sur l'année cible (ex: 29/01/2026 → 29/01/2016). Les sorties à venir dans les 15 jours sont grisées. Au-delà, elles sont chiffrées et nécessitent le reveal quotidien pour être dévoilées.

1) Choisis un saut temporel

Années disponibles selon ta date réelle (2026 → 2016, 2027 → 2017…)

2) Navigue par mois

Flèches + liste déroulante. Clique un jeu visible pour sa fiche Steam.

3) Reveal quotidien aléatoire

Une fois par jour, un tile masqué est révélé au hasard — sur toutes les années.

4) Mémoire locale

Reveals, jeux faits, préférences → localStorage. Export/Import save disponible.

Sélection de l'année
Les années se débloquent au fil du temps réel.
Tip : lance en python -m http.server 8000 pour éviter les blocages CORS.
